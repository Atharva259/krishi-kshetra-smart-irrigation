# krishi-kshetra-smart-irrigation
IoT and robotics-based smart irrigation system focused on agricultural automation, water conservation, and intelligent farming solutions.

## Overview
Krishi Kshetra is an agricultural automation and smart farming project focused on improving irrigation efficiency using IoT and embedded systems. The system automates water distribution based on real-time soil moisture conditions, helping farmers reduce water wastage, save electricity, and improve crop management.

This project is designed as an affordable and scalable smart farming solution for rural and semi-urban agricultural environments.

# Working Principle

1. The soil moisture sensor continuously monitors soil conditions.
2. Sensor values are processed by the microcontroller.
3. If soil moisture drops below the threshold:
   - Relay activates the water pump.
4. Once optimal moisture is reached:
   - Relay turns the pump OFF automatically.
5. The cycle repeats continuously for efficient irrigation.
