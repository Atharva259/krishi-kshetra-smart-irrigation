# Project Overview

## Krishi Kshetra Smart Irrigation System

Krishi Kshetra Smart Irrigation System is an IoT and robotics-based agricultural automation project designed to improve irrigation efficiency and support sustainable farming practices.

The system automates irrigation using real-time soil moisture monitoring and relay-controlled water pump management. By reducing manual intervention and preventing unnecessary water usage, the solution helps farmers optimize irrigation processes and improve crop management.

The project focuses on building affordable and scalable smart farming technology suitable for small and medium-scale agricultural environments.
